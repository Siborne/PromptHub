## Summary

`0.5.9` consolidates PromptHub's Skill, MCP, Plugin, Agent asset sync, CLI,
self-hosted Web, signed macOS delivery, shared database, and release workflows.
This replacement publication includes the post-release lifecycle and recovery
fixes completed on 2026-07-14.

The replacement keeps the stable `v0.5.9` URL but rebuilds every downloadable
artifact and the self-hosted Web image from the final release commit. An
already-installed `0.5.9` desktop client will not auto-update to another build
with the same semantic version; those users need a manual reinstall or a later
version such as `0.5.10`.

## Replacement Highlights

- Skill update checks resolve the exact local, Git, ZIP, content, or marketplace
  source into a validated full-package snapshot.
- The Skill update dialog shows every added, modified, and deleted file and lets
  the user explicitly retain the local package or apply the source package.
- Imported Agent/project Skills retain exact source identity and an installation
  baseline, including selector-aware nested Git repository paths.
- Invalid or unavailable AI safety services no longer turn a valid Skill into a
  false package error; local static findings remain visible and reviewable.
- Interrupted Skill installs are recovered on startup without leaving temporary
  repositories, half-written files, or orphaned database records.
- MCP custom sources are registered by the main process with exact origin/path
  trust, including explicit private-network authorization for user-added sources.
- Installed MCP templates retain source, version, and fingerprint baselines so
  upstream marketplace updates are distinct from local edits and Agent sync.
- Plugin updates reconcile complete package inventories and require review before
  applying source changes.
- Recoverable SQLite freelist corruption is rebuilt and revalidated before the
  application falls back to the existing recovery workflow.
- One application update check now renders one authoritative main-process state;
  development demo update injection has been removed.
- Deferred WebDAV, S3, and self-hosted startup sync now resumes reliably when a
  hidden window is revealed through menu, shortcut, tray-command, or
  second-instance paths.
- PromptHub Cloud account/store surfaces remain hidden in stable desktop builds
  unless the capability is explicitly enabled.
- macOS menu bar actions cover the primary PromptHub asset workspaces while using
  the dedicated monochrome Template image.
