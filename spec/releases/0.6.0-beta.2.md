## Summary

`0.6.0-beta.2` is the second preview of the 0.6 line. It adds whole-image
editing, Doubao Work Skill support, and repository Playwright Test Agents, while
hardening Git-less public Skill installation, Rules restore, upgrade recovery,
managed backup retention, updater sources, remembered close behavior, OpenCode
session discovery, and several Agent/Plugin/MCP persistence boundaries.

## Release Surfaces

- Root, Desktop, CLI, self-hosted Web, Cloudflare Worker, Mobile package, Expo
  metadata, and the standalone CLI runtime use `0.6.0-beta.2`.
- Private shared packages retain their independent `0.1.0` versions.
- Localized README preview rows and summaries target `v0.6.0-beta.2`.
- Stable badges, default downloads, website generated release metadata,
  Homebrew guidance, and GHCR `latest` remain on `v0.5.9`.
- Existing public screenshots remain unchanged. This preparation updates
  release metadata and notes; it does not claim a new public screenshot set.
