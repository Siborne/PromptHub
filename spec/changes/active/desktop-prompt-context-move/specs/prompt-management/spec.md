# Delta Spec

## Added

- Prompt 右键菜单新增“移动到...”入口。
- 右键菜单触发的文件夹选择弹层必须列出全部文件夹并支持移出当前文件夹。
- Prompt 右键菜单新增“折叠全部提示词”入口，用于折叠当前可见提示词树中所有带子节点的 Prompt。
- Prompt 右键菜单新增“移动到节点”入口，用于将当前 Prompt 移动到另一个 Prompt 节点或根节点。

## Modified

- 单条 Prompt 的文件夹迁移不再只能依赖拖拽或表格批量移动。
- 单条 Prompt 的树节点迁移不再只能依赖拖拽，右键菜单也必须复用既有 `parentId/order` 层级语义。

## Removed

- 无。

## Scenarios

- 当用户在任意 Prompt 视图中右键单条 Prompt 时，可以通过“移动到...”直接选择目标文件夹。
- 当用户选择“移出文件夹”时，该 Prompt 的 `folderId` 被清空并立即反映到列表中。
- 当用户选择“折叠全部提示词”时，当前可见提示词树里所有有子节点的 Prompt 被折叠。
- 当用户通过“移动到节点”选择另一个 Prompt 时，当前 Prompt 的 `parentId` 更新为目标 Prompt，且作为目标节点的末尾子节点。
- 当用户通过“移动到节点”选择根节点时，当前 Prompt 的 `parentId` 被清空并移动到根层级末尾。
- “移动到节点”不得列出当前 Prompt 自身或它的后代作为可选父节点。
