## Requirements

### `FR-APIMART-001`: First partner in every README language

All seven README languages must place APIMart in the first data row of the
existing one-column partner table. Infistar remains the next row with its
original content. Each APIMart row contains localized thanks, pricing, async API
workflow, batch/model-switching benefits, and pay-as-you-go registration copy.

### `FR-APIMART-002`: Supplied assets and registration destination

Simplified and Traditional Chinese use the supplied Chinese banner. English,
Japanese, German, Spanish, and French use the supplied English banner. Images
retain their original bytes. Both the banner link and text registration link
must point to `https://go.apimart.ai/gh-prompthub`. Full promotional posters are
not added.
