# APIMart README Sponsorship

## Purpose and Scope

Recognize APIMart as a sponsor in the existing partner table across all seven
README languages. The maintainer supplied the Chinese and English campaign
copy, two banner images, and the registration URL.

The scope is the root README, six localized README files, and two repository
banner assets. Website pages, the separate sponsor history, application code,
provider presets, release versions, and existing Infistar copy are unchanged.

## Risks and Rollback

Incorrect relative image paths or registration links could break the campaign.
Translations must preserve the supplied pricing and service claims. These are
sponsor-supplied claims; no provider pricing or performance acceptance was run.
Removing the APIMart rows and their two assets reverses the public change.

## Boundary Analysis

The existing Infistar record permits additional partners in the same table.
The maintainer explicitly requested APIMart first and localized copy for this
new campaign; the Infistar creative restrictions continue to apply to Infistar.
No storage, runtime, security, or public API contract changes are required.
